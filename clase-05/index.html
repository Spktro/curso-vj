Arranque

¿Y si tengo 50 enemigos?

❌ Copiar y pegar

Tres enemigos duplicados a mano. Querés cambiarles la velocidad… y tocás tres scripts. Con 50, es imposible.

✅ Instanciar

Un código crea 10 enemigos desde una sola plantilla. Modificás la plantilla y cambian todos.

💡 La solución se llama instanciación. Y para entenderla, primero un concepto más profundo: la Programación Orientada a Objetos.
Concepto

POO: organizar el caos

Sin organización, un RPG con 50 enemigos sería un mar de variables sueltas:

var vida_goblin = 30
var velocidad_goblin = 80
var vida_dragon = 500
var velocidad_dragon = 40
# ...imposible de mantener

Un objeto tiene 2 cosas

  • Datos (propiedades): qué sabe. vida = 100
  • Comportamiento (métodos): qué puede hacer. atacar()
🎮 Analogía RPG: un Guerrero tiene vida, fuerza, armadura (datos) y puede atacar(), bloquear() (métodos). La Maga tiene lo suyo. Ambos son de tipo Personaje.
POO

Los 4 pilares (versión principiante)

PilarQué significa
EncapsulamientoLos datos de un objeto son suyos. Otros los tocan a través de métodos, no directamente.
HerenciaUna clase hereda propiedades y métodos de otra. Mago hereda de Personaje.
PolimorfismoObjetos distintos responden distinto al mismo mensaje. atacar() difiere en Guerrero y Mago.
AbstracciónUsás el objeto sin saber cómo funciona por dentro.
Hoy nos concentramos en los primeros dos. Los otros aparecen solos a medida que el proyecto crece.
En Godot

Cada script .gd es una clase

extends CharacterBody2D   # hereda TODO de CharacterBody2D

# ── PROPIEDADES (datos de la clase) ──
var vida: int = 100
var nombre_personaje: String = "Héroe"

# ── MÉTODOS (comportamiento) ──
func recibir_dano(cantidad: int) -> void:
    vida -= cantidad
    if vida <= 0:
        morir()

func morir() -> void:
    print(nombre_personaje + " murió")
    queue_free()
extends es herencia en acción: tu clase arranca con todo lo de CharacterBody2D y le sumás lo tuyo.
Buena práctica

Tipado estático: : int, : float…

# Sin tipado (válido):
var vida = 100

# Con tipado (recomendado):
var vida: int = 100
var velocidad: float = 200.0
var nombre: String = "Héroe"
var tiene_espada: bool = false

Por qué conviene

  • El editor te avisa errores antes de ejecutar
  • Mejor autocompletado
  • El juego corre un poco más rápido
La magia

Instanciar = copias vivas de una escena

🍪 Analogía: una escena guardada es un molde de galletas. El molde no es la galleta: es la plantilla para hacer infinitas.

Cada galleta instanciada es independiente: la movés, la pintás o la destruís sin tocar el molde ni a las demás.

Instanciación

El flujo, en 4 pasos

extends Node2D

# 1. Cargar la escena plantilla (una sola vez)
var escena_enemigo = preload("res://enemigo.tscn")

func _ready():
    # 2. Crear una instancia (copia viva)
    var nuevo = escena_enemigo.instantiate()
    # 3. Configurarla
    nuevo.position = Vector2(300, 200)
    # 4. Agregarla a la escena para que exista
    add_child(nuevo)
Sin add_child(), la instancia existe en memoria pero no aparece en el juego.
Instanciación

preload() vs load()

FunciónCuándo usar
preload("ruta")Carga el recurso al compilar la escena. Más rápido en ejecución. Para cosas que siempre vas a usar.
load("ruta")Carga en tiempo de ejecución, cuando se necesita. Para contenido opcional o pesado, o cargas bajo demanda.
Regla simple: preload() para lo que siempre instanciás. load() para recursos opcionales o pesados.
Crear en tiempo real

Spawning: que aparezcan solos

extends Node2D
var escena_enemigo = preload("res://enemigo.tscn")
var tiempo_entre = 2.0
var timer = 0.0

func _process(delta):
    timer += delta
    if timer >= tiempo_entre:
        timer = 0.0
        spawnear()

func spawnear():
    var e = escena_enemigo.instantiate()
    e.position = Vector2(randf_range(50, 750), -30)
    add_child(e)
Spawning es la técnica detrás de que aparezcan enemigos, proyectiles, explosiones, monedas.

randf_range(a, b) da un número al azar entre a y b.

Spawning

El nodo Timer: más limpio

extends Node2D
var escena_enemigo = preload("res://enemigo.tscn")

func _ready():
    var timer = Timer.new()      # crear un Timer por código
    add_child(timer)
    timer.wait_time = 2.0
    timer.timeout.connect(spawnear)  # señal → función
    timer.start()

func spawnear():
    var e = escena_enemigo.instantiate()
    e.position = Vector2(randf_range(50, 750), -30)
    add_child(e)
El Timer emite la señal timeout cada wait_time. La conectamos a spawnear (¡señales, de la Clase 4!).
🎮 En juegos que conocés

Instanciar está en TODAS partes

👾 Space Invaders

Cada alien y cada disparo es una instancia de una plantilla. El clásico de 1978 ya usaba la idea.

🧛 Vampire Survivors / Brotato

Cientos de enemigos en pantalla, todos spawneados desde una misma escena. Toda la tensión sale de ahí.

🔫 Enter the Gungeon

Bullet hell: miles de balas a la vez. Cada bala es una instancia que se autoelimina al salir.

Si un juego tiene “muchos de algo que aparecen y desaparecen”, casi seguro es instanciación + spawning.
Spawning

Modificar y limpiar instancias

func spawnear():
    var e = escena_enemigo.instantiate()
    add_child(e)
    # tocar sus propiedades/métodos
    e.position = Vector2(300, 200)
    e.velocidad = 150.0

# eliminar todos los enemigos:
func limpiar():
    for e in get_children():
        if e.is_in_group("enemigo"):
            e.queue_free()
💡 Buena práctica: instanciá dentro de un nodo contenedor (ej. $Enemigos). Así la jerarquía queda limpia y borrás todo de una.
Integradora

Práctica: enemigos que caen

# Enemigo.tscn → script:
extends CharacterBody2D
var velocidad: float = 150.0

func _ready():
    add_to_group("enemigo")

func _physics_process(delta):
    velocity = Vector2(0, velocidad)  # hacia abajo
    move_and_slide()
    if position.y > 700:      # salió de pantalla

Lo que nos llevamos

ConceptoIdea clave
POOObjetos con datos (propiedades) y comportamiento (métodos). Cada script es una clase.
preload()Carga la escena plantilla al compilar.
instantiate()Crea una copia viva; add_child() la hace aparecer.
