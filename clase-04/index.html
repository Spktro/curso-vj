Concepto central

Tres tipos de cuerpos físicos

Nodo¿Para qué sirve?
StaticBody2DNo se mueve. Suelo, paredes, plataformas fijas. El motor lo respeta pero nunca lo mueve.
CharacterBody2DLo controlás vos por código. El personaje jugable, enemigos con IA. Sin gravedad automática.
RigidBody2DLo mueve el motor con física realista: gravedad, rebote, impulsos. Objetos que se tiran o explotan.
🎭 Analogía: CharacterBody2D es un actor que vos dirigís. RigidBody2D es un extra al que empujás y se cae solo.
Cuerpos físicos

La regla práctica

El jugador

Siempre CharacterBody2D. Control preciso, sin rebotes raros.

El suelo

Siempre StaticBody2D. Fijo, sólido, no se mueve nunca.

Lo que se tira

Siempre RigidBody2D. Cajas, barriles, proyectiles físicos.

📏 Elegir el nodo correcto es la mitad del trabajo. El tipo define cómo interactúa con el mundo.
🎮 En juegos que conocés

Cada tipo, en un juego real

🟩 StaticBody2D

🟦 CharacterBody2D

El salto de calidad

¿Por qué no alcanza con position.x += ...?

En la Clase 3 movíamos cambiando position directamente. Sirve para objetos que no chocan con nada.

Pero si el personaje tiene que frenar contra una pared o pisar el suelo, alguien tiene que resolver esas colisiones. Ese alguien es el motor.

🚗 move_and_slide()

Mueve el CharacterBody2D usando su variable velocity, detecta las colisiones en el camino y ajusta el movimiento automáticamente — incluso deslizándose por las paredes.

El patrón que van a usar siempre

Movimiento de plataformas, paso a paso

extends CharacterBody2D

const VELOCIDAD = 200.0
const GRAVEDAD = 900.0
const FUERZA_SALTO = -400.0  # negativo = arriba (Y invertido)

func _physics_process(delta):
	# 1. Gravedad: se acumula en el aire
	if not is_on_floor():
		velocity.y += GRAVEDAD * delta
	# 2. Input horizontal: -1 / 0 / 1
	var dir = Input.get_axis("mover_izquierda", "mover_derecha")
	velocity.x = dir * VELOCIDAD
	# 3. Salto: solo si toca el suelo
	if Input.is_action_just_pressed("saltar") and is_on_floor():
		velocity.y = FUERZA_SALTO
	# 4. Que Godot resuelva las colisiones
	move_and_slide()
Qué hace cada parte

Las cuatro partes del patrón

PasoQué hace
1 · Gravedadvelocity.y += GRAVEDAD * delta — se acumula (por eso +=) mientras not is_on_floor(). Sin esto, flota.
2 · Inputget_axis() devuelve un número entre -1 y 1. Multiplicado por la velocidad, da la dirección horizontal.
3 · SaltoUn impulso hacia arriba (velocity.y negativo), solo si está en el suelo — si no, saltaría en el aire.
4 · Movermove_and_slide() aplica velocity, resuelve choques y actualiza is_on_floor().
🎮 Este patrón es el corazón de Celeste, Super Meat Boy y cualquier plataformero de precisión.
Dónde va cada cosa

_process vs _physics_process

FunciónCuándo usarla
_process(delta)Lógica general: input de menús, UI, estados. No toca la física.
_physics_process(delta)Todo lo que usa física y colisiones. Se llama a frecuencia fija (60 Hz), estable siempre.
📏 Regla: si usás move_and_slide() o manejás colisiones, va en _physics_process(). Todo lo demás puede ir en _process().
Sin esto, nada choca

CollisionShape2D: la silueta física

Un cuerpo físico por sí solo no tiene forma. Necesita un nodo hijo CollisionShape2D que define su “silueta” para las colisiones.

⚠️ Error frecuente: si el personaje no colisiona con nada, casi seguro falta el CollisionShape2D o su shape está vacío.
ShapeIdeal para
RectangleShape2DPersonajes humanoides y cajas. La más común.
CapsuleShape2DPersonajes que se deslizan suave por esquinas.
CircleShape2DObjetos redondos: pelotas, monedas.

Parte 2 · Comunicación

¿Qué son las Señales?

El sistema de comunicación de Godot. Permiten que un nodo avise que pasó algo, sin que los nodos necesiten conocerse.

❌ Sin señales: la moneda busca el marcador y lo modifica a mano. Si cambiás un nombre, todo se rompe.

🔔 Analogía: la campana

La moneda toca una campana cuando la agarran. Cualquiera que esté “escuchando” reacciona.

La moneda no sabe quién escucha — solo toca la campana. Eso las hace flexibles.

Señales

El flujo de una señal

1 · Emitir

Un nodo emite la señal cuando ocurre algo

→

2 · Conectar

Otro nodo conecta la señal a una de sus funciones

→

3 · Reaccionar

Al emitirse, la función conectada se ejecuta sola

🎮 Así funcionan los logros de Steam, el puntaje que sube al juntar un anillo en Sonic, o el “¡Nivel completado!” cuando cruzás la meta.
Señales predefinidas

Area2D: el detector de zonas

Detecta cuándo otros cuerpos entran o salen de una zona. No bloquea el paso (a diferencia de StaticBody2D): solo detecta.

Perfecto para monedas, poderes, zonas de daño y disparadores de eventos.
SeñalCuándo se emite
body_entered(body)Entra un CharacterBody2D o RigidBody2D. Daño, recolección.
body_exited(body)El cuerpo sale del área.
area_entered(area)Entra otra Area2D. Zona contra zona.
🎮 Los anillos de Sonic, las monedas de Mario, los pinchos y la lava, los checkpoints: todos son Area2D escuchando body_entered.
Conectar señales · editor

Conectar una señal sin código

  1. Seleccioná el nodo Area2D
  2. Panel lateral Node → Signals
  3. Doble clic en body_entered
  4. Elegí el nodo que va a recibir la señal
  5. Connect

Godot genera la función sola en el script del receptor.

# Función generada automáticamente
func _on_area_2d_body_entered(body):
	# 'body' es el nodo que entró
	print("Algo entró: " + body.name)
Conectar señales · código

Conectar una señal por código

# En _ready() del nodo receptor:
func _ready():
	# Buscar el Area2D y conectar su señal a nuestra función
	$Area2D.body_entered.connect(_on_moneda_tocada)

func _on_moneda_tocada(body):
	if body.is_in_group("jugador"):
		puntos += 1
		queue_free()   # eliminar la moneda
⚠️ Si la señal no dispara: verificá que el Area2D tenga un CollisionShape2D hijo con shape asignado. Sin shape, el área no tiene volumen y nunca detecta nada.
Comunicación masiva

Grupos: un megáfono para muchos nodos

Permiten etiquetar nodos para hablarle a todos los de ese tipo a la vez. En vez de señales uno a uno, es un megáfono.

🎮 Una explosión que le pega a todos los enemigos a la vez, o un hechizo que congela a todo lo etiquetado como "enemigo".
# Etiquetar un nodo (en _ready):
func _ready():
	add_to_group("jugador")

# ¿Pertenece a un grupo?
if body.is_in_group("jugador"):
	print("El jugador tocó el área")

# Llamar una función en TODO un grupo:
get_tree().call_group("enemigos", "recibir_dano", 50)
También se etiqueta desde el editor: nodo → pestaña Node → Groups.

Práctica: un nivel con monedas

El jugador se mueve, salta, y al tocar una moneda la recoge y suma puntos.

Estructura de la escena

Nivel (Node2D)
├── Jugador (CharacterBody2D)
│   ├── Sprite2D
│   └── CollisionShape2D
├── Suelo (StaticBody2D)
│   └── CollisionShape2D
└── Moneda (Area2D)
    ├── Sprite2D
    └── CollisionShape2D
Junta todo lo de hoy: los tres cuerpos físicos, move_and_slide(), una señal de Area2D y un grupo.

🎮 Es el esqueleto de Mario juntando monedas o Sonic juntando anillos.

Práctica · 1 de 2

Script del Jugador

extends CharacterBody2D

const VELOCIDAD = 250.0
const GRAVEDAD = 980.0
const SALTO = -450.0
var puntos = 0

func _ready():
	add_to_group("jugador")
	print("Jugador listo. Puntos: " + str(puntos))
func _physics_process(delta):
	if not is_on_floor():
		velocity.y += GRAVEDAD * delta
	var dir = Input.get_axis("mover_izquierda", "mover_derecha")
	velocity.x = dir * VELOCIDAD
	if Input.is_action_just_pressed("saltar") and is_on_floor():
		velocity.y = SALTO
	move_and_slide()
func sumar_punto():
	puntos += 1
	print("¡Moneda! Puntos: " + str(puntos))
Práctica · 2 de 2

Script de la Moneda

extends Area2D

func _ready():
	body_entered.connect(_on_body_entered)

func _on_body_entered(body):
	if body.is_in_group("jugador"):
		body.sumar_punto()   # función del jugador
		queue_free()         # eliminar la moneda

Cómo se conecta todo

  • La moneda emite body_entered
  • Chequea que sea del grupo "jugador"
  • Le pide al jugador sumar_punto()
  • Se autoelimina con queue_free()
