Bloque 3 ● EN VIVO

Un récord que no se borra

# partida.gd (Autoload)
const RUTA = "user://guardado.json"

# kills, tiempo, mejor_tiempo y reiniciar(), como estaban

func _ready():
	cargar()

func guardar():
	var datos = {"mejor_tiempo": mejor_tiempo}
	var archivo = FileAccess.open(RUTA, FileAccess.WRITE)
	archivo.store_string(JSON.stringify(datos, "\t"))

func cargar():
	if not FileAccess.file_exists(RUTA):
		return
	var texto = FileAccess.get_file_as_string(RUTA)
	var datos = JSON.parse_string(texto)
	if datos == null:
		print("No se pudo leer ", RUTA)
		return
	mejor_tiempo = datos.get("mejor_tiempo", 0.0)

# game_over.gd, dentro del if del récord
		Partida.mejor_tiempo = Partida.tiempo
		Partida.guardar()

Bloque 3 · línea por línea

Qué hace cada pieza nueva

LíneaQué hace
const RUTA = "user://guardado.json"La ruta en un solo lugar: si cambia, se cambia una vez.
cargar() en _ready() de PartidaEl Autoload arranca antes que cualquier escena: el menú ya tiene los datos.
JSON.stringify(datos, "\t")El diccionario como texto. El "\t" lo escribe con sangría, una clave por línea.
JSON.parse_string(texto)El texto como diccionario otra vez, o null si está roto.
datos.get("ranking", [])El valor de la clave, o el segundo si no está.
str(int(fila["tiempo"]))Del JSON vuelve 37.0: int() le saca el .0.

Desafío · opcional

Una estatua que guarda la partida

  1. estatua.tscn: un Area2D con un cartel E: guardar que aparece si el caballero está cerca
  2. Con E: Partida.guardar_checkpoint(jugador) escribe checkpoint.json
  3. En el menú, Continuar solo si FileAccess.file_exists()
  4. Continuar lee el archivo y la arena lo aplica en su _ready()
Pista: el _ready() de la Arena corre después del de sus hijos. Ahí el HUD ya existe y el caballero ya puso su vida en 100.

Para decidir

Al morir, ¿se borra el checkpoint (otra vez de cero) o se vuelve a la estatua?

Desafío · pistas

Guardar en la estatua, aplicar en la arena

# arena.gd: corre después que sus hijos
func _ready():
	if Partida.checkpoint != null:
		var datos = Partida.checkpoint
		$Jugador.vida = int(datos["vida"])
		$Jugador.position = Vector2(datos["x"], datos["y"])
