Animación Godot · demo 03

Tween: animar desde el código

# flash: rojo, y vuelve a blanco en 0.15 s
$AnimatedSprite2D.modulate = Color(1, 0.3, 0.3)
var tween = create_tween()
tween.tween_property($AnimatedSprite2D, "modulate", Color.WHITE, 0.15)

# pop: se infla, se desvanece y se borra
var t = create_tween()
t.tween_property(self, "scale", Vector2(1.5, 1.5), 0.1)
t.tween_property(self, "modulate:a", 0.0, 0.15)
t.tween_callback(queue_free)

tween_property(nodo, "propiedad", valor, segundos)

  • Los pasos van en orden
  • No hace falta agregar un nodo

Sonido Godot · demo 05

El slime muere… y se lleva su sonido

❌ No suena

func morir():
	$SfxMuerte.play()
	queue_free()   # se borra con su hijo

✅ Esperar a que termine

func morir():
	$SfxMuerte.play()
	hide()
	set_deferred("monitorable", false)
	remove_from_group("enemigo")
	await $SfxMuerte.finished
	queue_free()
Otra salida, la del TP: que el sonido lo toque el jugador.

Efectos Godot · demo 08

Screenshake: la cámara tiembla

func sacudir_camara():
	var camara = get_node("../Camara")
	var tween = create_tween()
	for i in 5:
		var salto = Vector2(randf_range(-6, 6), randf_range(-6, 6))
		tween.tween_property(camara, "offset", salto, 0.03)
	tween.tween_property(camara, "offset", Vector2.ZERO, 0.03)
  • Camera2D en 0, 0, Anchor Mode: Fixed Top Left
  • 6 px al recibir daño; nada al disparar
Efectos Godot · demo 09

Hit stop: congelar el tiempo un instante

func frenar_tiempo():
	Engine.time_scale = 0.05
	# 0.06 s reales: el último true ignora time_scale
	await get_tree().create_timer(0.06, true, false, true).timeout
	Engine.time_scale = 1.0
  • 60 ms no se ven: se sienten
  • Solo golpes grandes: el jefe, no cada slime
Efectos Godot · demo 10

Partículas: crearlas desde el código

func explotar():
	var p = CPUParticles2D.new()
	p.one_shot = true
	p.amount = 24
	p.lifetime = 0.8
	p.explosiveness = 1.0
	p.spread = 180
	p.gravity = Vector2.ZERO
	p.initial_velocity_min = 160
	p.initial_velocity_max = 260
	p.position = position
	p.finished.connect(p.queue_free)
	get_parent().add_child(p)
	p.emitting = true
  1. Crear con new()
  2. Configurar
  3. Que se borre al terminar
  4. Agregar a la arena, no al slime
  5. Emitir
