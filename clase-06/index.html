La cara del juego

HUD, menús y CanvasLayer: la capa que le habla al jugador. Label, Button, ProgressBar y cambio de escenas.

“La UI no es decoración: es comunicación entre el juego y el jugador.”

Arranque

¿Cuántas monedas tengo? ¿Cuánta vida?

Sin UI

El personaje se mueve y recoge monedas. Pero… no hay forma de saber cuántas tiene ni cuánta vida le queda.

Con UI

Misma mecánica, pero con un contador arriba a la derecha y una barra de vida arriba a la izquierda.

Sin UI, el jugador no puede tomar decisiones informadas. La interfaz es el puente de información.
Concepto

Nodos Control: viven en la pantalla

Los nodos de interfaz son de tipo Control. A diferencia de los 2D, se posicionan relativo a la pantalla, no al mundo.

Cuando la cámara se mueve, el mundo se corre pero la UI se queda quieta.

⚠️ El problema

Si ponés la UI como hija del jugador o del nivel, se mueve con la cámara y se ve mal. La solución es CanvasLayer.

Control

CanvasLayer: la capa que no se mueve

Crea una capa de renderizado independiente. Todo lo que sea hijo de un CanvasLayer se dibuja en posición fija respecto a la pantalla, sin importar la cámara.

  • Todo el HUD (puntos, vida, íconos) va ahí adentro
  • Los menús también, o en escenas separadas

Control

Los nodos de Control principales

NodoPara qué sirve
LabelMuestra texto estático o dinámico. Puntaje, nombre, diálogos.
ButtonBotón clickeable. Emite la señal pressed() al hacer clic.
ProgressBarBarra de progreso. Ideal para vida, maná, carga.
TextureRectMuestra una imagen. Íconos, fondos, arte de UI.
VBox/HBoxContainerOrdenan a los hijos en columna o fila, solos.

Mostrar info

Label: texto que cambia

extends CanvasLayer

# Referencias a los nodos de UI
@onready var label_puntos = $PanelPuntos/LabelPuntos
@onready var label_vida = $PanelVida/LabelVida

# El jugador llama estas funciones cuando cambian los valores
func actualizar_puntos(puntos: int) -> void:
    label_puntos.text = "Puntos: " + str(puntos)

func actualizar_vida(vida: int) -> void:
    label_vida.text = "Vida: " + str(vida)
Atajo clave

@onready: acceso limpio a nodos

# Forma moderna ✅
@onready var mi_label = $Label

# Forma clásica (equivalente):
var mi_label
func _ready():
    mi_label = $Label
@onready asigna la variable cuando el nodo está listo (en _ready()), pero en una sola línea. Lo vas a usar todo el tiempo.

$Nodo busca un nodo hijo por su nombre en el árbol.

ProgressBar

Barra de vida con color

@onready var barra_vida = $BarraVida

func actualizar_vida(actual: int, maxima: int) -> void:
    barra_vida.max_value = maxima
    barra_vida.value = actual
    # Cambiar color según el nivel de vida
    if actual <= maxima * 0.25:
        barra_vida.modulate = Color.RED      # crítica
    elif actual <= maxima * 0.5:
        barra_vida.modulate = Color.YELLOW   # baja
    else:
        barra_vida.modulate = Color.GREEN    # normal
💡 Nunca hardcodees el 100. Guardá la vida máxima en una variable y calculá porcentajes: si mañana hay 150 de vida, no se rompe nada.
Menús

Button: la señal pressed()

extends Control   # los menús usan Control como raíz

@onready var boton_jugar = $BtnJugar
@onready var boton_salir = $BtnSalir

func _ready():
    boton_jugar.pressed.connect(_on_jugar_pressed)
    boton_salir.pressed.connect(_on_salir_pressed)

func _on_jugar_pressed() -> void:
    get_tree().change_scene_to_file("res://nivel_1.tscn")

func _on_salir_pressed() -> void:
    get_tree().quit()
💬 Diseño: el texto del botón describe la acción, no el resultado: “Jugar”, no “Empezar partida nueva”. Corto y claro.
Navegación

Cambiar de escena

# Ir a otra escena por su ruta
get_tree().change_scene_to_file("res://escenas/nivel_1.tscn")

# Reiniciar la escena actual
get_tree().reload_current_scene()

# Pausar el juego (la UI sigue activa)
get_tree().paused = true

# Cerrar el juego
get_tree().quit()
⚠️ Si el cambio “no funciona”, revisá la ruta res://: tiene que coincidir exactamente con la ubicación del .tscn en el FileSystem.
Diseño práctico

Estructura de un HUD completo

Árbol recomendado

HUD (CanvasLayer)
└── HBoxContainer # fila superior
    ├── Panel # izq
    │   └── BarraVida
    └── Panel # der
        └── LabelPuntos
Los contenedores (HBox, VBox) acomodan los hijos solos. La UI así sobrevive a cualquier resolución.
HUD

Conectar el HUD con el jugador

# En el HUD (CanvasLayer):
func set_puntos(valor: int):
    label_puntos.text = "× " + str(valor)

func set_vida(actual: int, maximo: int):
    barra_vida.value = actual
    barra_vida.max_value = maximo
# En el JUGADOR:
@onready var hud = $"../HUD"

func recoger_moneda():
    puntos += 1
    hud.set_puntos(puntos)

func recibir_dano(cant: int):
    vida -= cant
    hud.set_vida(vida, vida_maxima)
El jugador avisa al HUD cuando algo cambia. El HUD solo se encarga de mostrar.
Integradora

Práctica: menú principal + HUD

A · Menú principal

  • MenuPrincipal.tscn: fondo, título (Label grande), botones Jugar y Salir
  • Jugar → lleva al nivel
  • Setearlo como Main Scene en Project Settings

B · HUD en el nivel

  • CanvasLayer “HUD”
  • Label de puntos (arriba der.) + ProgressBar de vida (arriba izq.)
  • Conectarlo al jugador
  • Botón “Menú” que vuelve al inicio
🏆 Extra: pantalla de Game Over con botón “Reintentar” y la puntuación final.
Cierre

La UI es comunicación

🧭 Repaso

  • CanvasLayer: capa de UI que no se mueve con la cámara
  • Nodos Control se posicionan respecto a la pantalla
  • @onready asigna un nodo hijo al estar listo
  • pressed() responde a los clics de botón
  • change_scene_to_file() cambia de escena
